# Desktop fonts

These fonts make the LuaLaTeX PDF build independent of system-installed
fonts. They are redistributed under the SIL Open Font License 1.1; see the
license files in the parent directory.

- Roboto Condensed 3.016 (`.ttf`), from the official
  [Google Fonts release](https://github.com/googlefonts/roboto-3-classic/releases/tag/v3.016).
  The upstream project distributes its current desktop fonts as TTF-flavored
  OpenType fonts rather than `.otf` files.
- STIX Two 2.13 b171 (`.otf`), from the official
  [STIX Fonts release](https://github.com/stipub/stixfonts/releases/tag/v2.13b171).
